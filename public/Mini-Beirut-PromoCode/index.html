About Mini Beirut

Mini Beirut serves Lebanese food in Egypt, from mezze to main dishes. Foodidu has two codes for it: BEIRUT25 for 25% off, and AUTO15 for 15% off when you order directly from the Mini Beirut website.

Mini Beirut code: FAQ

What is the Mini Beirut promo code?

Mini Beirut codes on Foodidu: AUTO15 (15% off when you order on the website) and BEIRUT25 (25% off your order).

How do I use the Mini Beirut code?

Copy AUTO15 or BEIRUT25, open the Mini Beirut website, add your order to the cart and paste the code in the promo code field at checkout.

Are there any conditions?

AUTO15: 15% off when you order directly from the Mini Beirut website. BEIRUT25: 25% off your order from Mini Beirut.

Why isn't the Mini Beirut code working?

Check that your order meets the conditions (for example first order only or a minimum amount) and that you typed the code exactly as shown. Offers are set by Mini Beirut and can change or end at any time. If it still fails, try another code on Foodidu.
